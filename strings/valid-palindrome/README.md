# Valid Palindrome

## Problem

Check whether a given string is a palindrome after ignoring non-alphanumeric characters and case.

## Approach

I use two pointers. One starts from the beginning and the other from the end. I compare the characters after ignoring spaces, symbols, and letter case.

## Example

Input:

"A man, a plan, a canal: Panama"

Output:

true

## Complexity

Time Complexity: O(n)

Space Complexity: O(1)

## Test Case

Input: "A man, a plan, a canal: Panama"

Expected Output: true
