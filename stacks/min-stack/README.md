# Min Stack

## Problem

Design a stack that supports push, pop, top, and retrieving the minimum element.

## Approach

I use a stack and keep track of the minimum value. This allows the minimum value to be found efficiently.

## Example

Operations:

push(-2)
push(0)
push(-3)
getMin()

Output:

-3

## Complexity

Time Complexity: O(1) for each operation

Space Complexity: O(n)

## Test Case

Input operations:

push(-2), push(0), push(-3), getMin()

Expected Output:

-3
